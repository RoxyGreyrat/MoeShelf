# 界面改版说明（1.6.2）

本次改版只涉及**前端展示层**：`src/app/**`、`src/lib/ui-shared.ts`、`src/components/**`。
**API、SQLite 存储、刮削逻辑、`desktop/` 与打包脚本均未改动**，数据格式与 1.6.1 完全兼容。

---

## 1. 设计令牌（Design Token）

新增暗 / 亮同源的一套 CSS 变量（`src/app/globals.css`）：

| 分类 | 变量 |
|---|---|
| 表面 | `--surface-0..3` / `--surface-glass` / `--surface-sunken` / `--surface-hover` |
| 文字 | `--text-1..4`（主 / 次 / 弱 / 装饰） |
| 描边 | `--line-1..3` |
| 强调与语义 | `--accent*` / `--success*` / `--warn*` / `--danger*` |
| 布局 | `--header-h` / `--rail-w` / `--aside-w` / `--content-max` |
| 卡片密度 | `--density-min` / `--density-gap` / `--card-title` / `--card-line` / `--card-pad` |

配套的语义化类：`text-primary|secondary|tertiary|quaternary`、`bg-surface-*`、`bg-sunken`、`border-hairline|subtle|strong`、
`btn` + `btn-sm|md|lg` + `btn-primary|success|ghost|soft`、`icon-btn`、`overlay-btn`、`chip`、`segment`、`field`、`panel`、`section-label`。

亮色主题只替换这一组变量值，**不再使用 `[class*='text-white/']` 这类属性通配符覆盖**——那是此前亮色正文对比度只有约 3:1 的根因。

---

## 2. 排版尺度：全部改 rem

- 全站 16 档像素字号改为 rem（`text-[0.8125rem]` 等），Tailwind 默认字号整体上调一档。
- 最小字号 11px → 12px；卡片标题 13px → 15px；卡片副信息 12px → 13px。
- **界面缩放在设置里生效范围变了**：此前只放大间距（字号是 px，固定不变），现在会真正按比例放大文字。

---

## 3. 布局与滚动

```
顶栏（吸顶，60px：品牌 / 搜索 / 扫描 / 主题 / 设置）
├─ 左栏 232px（吸顶，可折叠为 52px）：概览 · 全部游戏 · 我的收藏 · 厂商（可搜索/渐进展开）
├─ 主区：吸顶工具条（结果数 · 排序 · 仅收藏 · 密度）+ 单一滚动区 + 卡片网格（auto-fill）
└─ 右栏 264px（吸顶）：总时长 + 游戏/通关/收藏 ｜ 最近启动 ↔ 已通关（分段切换）
```

- 主区单一滚动条；左栏与右栏 `sticky`。
- 切换厂商 / 搜索 / 排序：自动回到顶部并重置分页。
- 列数由 `auto-fill` 决定（原先是写死的 `xl:5 2xl:5`）：1920 → 6 列，2560 → 8 列。

---

## 4. 卡片

- 两段式信息区：标题（15px/600）→ 发售日 · 厂商（13px）→ 时长徽章 + 文件夹（12px）。
- **游玩时长为 0 时不再渲染**「0 分钟」（原实现每张卡都带这个前缀）。
- 角标从 7 种收敛为 3 种（收藏星 / 通关勾 / 未下载虚线边框）。
- 浮层操作统一为 `overlay-btn`：桌面端悬停才出现；移动端收进 `…` 菜单（查看详情 / 打开文件夹 / 重新获取 / 移除）。
- 「启动」按钮 32px 高，去掉渐变与发光。

---

## 5. 详情弹窗与设置弹窗

**详情弹窗**
- 顶部操作栏：标题 + 通关标记 + 原名｜启动 / 打开文件夹 / 重新获取 / 更多设置 / 关闭。
- 左栏：封面 + 评分 / 发售日 / 厂商 / 时长四张信息卡。
- 右栏：简介 ↔ 角色与声优（标签页），弹窗内嵌滚动由 2 处降为 0。
- 高度按内容自适应、上限 92vh（原先是固定 92vh，简介短时下方大片空白）。
- 路径与启动文件移到右栏底部信息带（可切换 exe）。

**高级设置（原「设置」）**
- 左侧分组导航：基本信息 / 识别与匹配 / 运行 / 扩展数据；右侧为当前分组内容（单选手风琴）。
- 输入框、按钮、面板统一使用令牌，修复亮色主题下部分输入框「深底深字」。

---

## 6. 关键修复

- **厂商视图只显示部分游戏**：原实现是「先分页取前 60 个，再按厂商过滤」，被过滤掉的卡片仍占用分页额度——表现为柚子社 13 个游戏只渲染出 3 个（其余散落在前 60 名之外，根本没进 DOM）。现改为**先筛选再分页**，并移除 `display:none` 占位。
- 修复厂商底部「再显示 N 个」在本地游戏不足一页时仍出现的问题。
- 未下载（VNDB 刮削）卡片增加「只看本地已有的」开关。

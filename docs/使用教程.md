## 第 0 章 · 准备：我需要什么

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 系统 | Windows 10 / 11（64 位） | 发布包是 `windows-x64`；macOS / Linux 可以走[源码运行](#第-10-章--从源码运行进阶) |
| **Node.js** | **20 或更高**（20 / 22 / 24 都行） | **很多人卡在这一步**，见第 1 章。没有它程序起不来 |
| 浏览器 | Edge / Chrome / Firefox 任一 | 界面跑在浏览器里 |
| 磁盘 | 视游戏库大小 | 程序本体约 200 MB，封面缓存随库增长 |
| 网络 | 能访问 vndb.org / bgm.tv 等 | 刮削才需要；纯本地浏览不联网也能用 |

要下载的东西只有一个：**GitHub Releases 里的 `Moeshelf-<版本>-windows-x64.zip`**
→ <https://github.com/RoxyGreyrat/MoeShelf/releases/latest>

> 压缩包里**已经带了全部依赖**（`node_modules`），所以**不需要**执行 `npm install`，也不需要联网装东西。
> 它唯一需要的本机环境就是 **Node.js 本身**。

## 第 1 章 · 电脑上没有 Node 运行环境怎么办（重点）

### 1.1 先确认自己有没有

按 `Win + R`，输入 `cmd` 回车，打开黑色命令行窗口，输入：

```bat
node -v
```

- 显示 `v20.x.x` / `v22.x.x` / `v24.x.x` 之类 → **已经装好了**，跳到[第 2 章](#第-2-章--解压与放置)
- 显示 `'node' 不是内部或外部命令` → **没装**，继续往下看

### 1.2 为什么要装 Node

MoeShelf 的 Web 版是「浏览器界面 + 本机 Node 服务端」的结构：界面在浏览器里显示，数据读写、刮削、启动游戏都由本机的 Node 进程完成。所以**装一次 Node 就够了**，之后每天用只要双击 `启动.bat`。

### 1.3 安装（推荐：官方 msi 安装包）

1. 打开官网中文页：<https://nodejs.org/zh-cn>
2. 下载 **LTS 版本**（当前是 22.x；只要 ≥ 20 都行），选 **Windows 安装包 (.msi) 64-bit**
   - 官网下载慢的话，可用国内镜像：<https://npmmirror.com/mirrors/node/>（选 `v22.x.x/node-v22.x.x-x64.msi`）
3. 双击安装，一路「下一步」，**注意保持勾选 `Add to PATH`**（默认就是勾上的，别取消）
4. 安装完成后**关掉之前那个命令行窗口**，重新 `Win + R` → `cmd` → 再输一次：

```bat
node -v
npm -v
```

两条都能打印版本号，就装好了。

### 1.4 免安装版（公司电脑不给装软件 / 没有管理员权限时）

1. 到镜像站下载 **`node-v22.x.x-win-x64.zip`**（注意是 zip，不是 msi）
2. 解压到比如 `D:\nodejs`（最终应该能在 `D:\nodejs\node.exe` 看到文件）
3. 把这个目录加进 PATH：
   - `Win + R` → `sysdm.cpl` → 「高级」→「环境变量」
   - 在**用户变量**里找到 `Path` → 编辑 → 新建 → 填 `D:\nodejs` → 确定
4. 重新打开 `cmd`，`node -v` 能打印版本号即可

> 加 PATH 只是为了 MoeShelf 能找到 `node`。如果不想改 PATH，也可以每次都用命令行的绝对路径启动，但那样很麻烦，不推荐。

### 1.5 装 Node 时的常见坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 装完 `node -v` 还是「不是内部或外部命令」 | 旧的命令行窗口没关，PATH 没刷新 | 关掉所有 cmd / 终端窗口，重新开一个 |
| 重开还是不行 | 安装时取消了 `Add to PATH` | 重新运行 msi，选 `Change` 补上；或用 1.4 的免安装版手动加 |
| `node -v` 显示 `v18.x` | 版本太低，装不上数据库模块 | 卸掉旧版，装 20 或更高的 LTS |
| 公司电脑不允许安装 | 无管理员权限 | 用 1.4 的免安装 zip 版，不需要管理员 |
| 下载很慢 / 卡在 0% | 网络原因 | 用上面的 npmmirror 镜像 |

### 1.6 装好 Node 之后还要做什么

**什么都不用做。** 不用 `npm install`、不用配环境变量、不用改配置——直接进第 2 章解压启动包即可。

## 第 2 章 · 解压与放置

1. 到 <https://github.com/RoxyGreyrat/MoeShelf/releases/latest> 下载 `Moeshelf-<版本>-windows-x64.zip`
2. 解压到一个**固定、好找、路径短**的位置，例如：

```text
D:\MoeShelf\           ← 推荐
E:\Tools\MoeShelf\     ← 也可以
```

解压后目录里应该有这些：

```text
MoeShelf\
├── 启动.bat              ← 日常就双击它
├── MoeShelf.exe          ← 同样的启动器（双击也可）
├── 开启局域网访问.bat      ← 手机访问时才用（需管理员）
├── server.js
├── node_modules\
├── .next\
├── README.md
└── 更新日志.md
```

第一次启动后会自动多出一个 `data\` 目录，**你的全部数据都在里面**，别删。

**放置位置的三个建议**

- 别放在「下载」文件夹或桌面：容易被清理软件顺手删掉，也容易和同步盘打架
- 别放在 OneDrive / 坚果云等同步目录：`data\` 里的数据库在运行时会被频繁写入，同步盘容易产生冲突副本
- 路径里有中文、空格一般没问题，但**越短越省事**

## 第 3 章 · 第一次启动

1. 双击 **`启动.bat`**（或 `MoeShelf.exe`）
2. 会弹出一个**黑色命令行窗口**，里面会打印类似：

```text
URL: http://localhost:3000
Phone access (same WiFi): http://192.168.1.64:3000
Press Ctrl+C to stop the server
```

3. 浏览器通常会自动打开 `http://localhost:3000`。如果没自动打开，手动在浏览器里输入 `http://localhost:3000`
4. 看到 MoeShelf 界面（首次是空态引导）就成功了

### ⚠️ 那个黑窗口千万别关

**黑窗口就是服务本身**。关掉窗口 = 关掉程序，浏览器页面会立刻打不开——这是新手最常踩的坑。

- 想最小化可以最小化，别点 ×
- 想停止程序：在黑窗口里按 `Ctrl + C`，或直接关窗口
- 想再次使用：重新双击 `启动.bat` 即可

### 端口被占用怎么办

如果 3000 被别的程序占用，启动器会**自动往后找** 3001 ~ 3019，并把这行打印在黑窗口里：

```text
Port 3000 is busy, using 3001 instead.
URL: http://localhost:3001
```

所以**以黑窗口里打印的 URL 为准**。全都占用时会提示启动失败，关掉占端口的程序再启动。

## 第 4 章 · 设置游戏根目录并扫描

MoeShelf 的模型是：**你指定一个「游戏根目录」，它把该目录下的每个一级子文件夹当作一个游戏**。

```text
D:\Galgame\              ← 把这个目录填进设置
├── 9-nine-新章\           ← 一个游戏
│   ├── 9-nine-NewEpisode.exe
│   └── ...
├── 夏日口袋REFLECTION BLUE\ ← 一个游戏
└── ...
```

操作步骤：

1. 点右上角 **「扫描游戏」** 旁边的**设置**图标（齿轮）
2. 在「**游戏根目录**」一栏点选择目录，选中你的游戏根目录 → **「保存并扫描」**
3. 程序开始扫描：识别文件夹、挑出主程序 exe（会自动排除安装器、卸载器、运行库）
4. 扫描完成后回到主界面，卡片就出来了

**扫描阶段的小知识**

- 只扫**一级子文件夹**。如果你的结构是 `D:\Galgame\厂商\游戏名\`，请把根目录设到更细一层，或者用「只看本地已有的」这类筛选配合
- 没识别出可执行文件的条目会标记为「未下载」，它们仍然可以刮削信息（用来做收藏规划）
- 扫描不会移动、修改你的游戏文件，只是读取

## 第 5 章 · 刮削：封面、标题、中文简介

扫描完成后，程序会按顺序向 **VNDB → Bangumi → YMgal → CnGal → Moyu** 请求元数据，自动补上封面、发售日、评分、会社、中文标题、中文简介、角色与声优。

**刮削是后台慢慢跑的**，卡片上会有加载状态；没刮到的可以随时手动补。

### 5.1 刮削失败 / 信息不对

在卡片上点开详情 → 右上角 **「重新获取信息」**；匹配错了就进 **「更多设置 → 修正条目」**，在五个数据源里重新搜索选择正确的条目。

### 5.2 中文简介：换源与手动改（1.7.0 新增）

打开详情弹窗，右栏「**简介**」标签旁边有两个控件：

- **来源下拉**（显示当前来源：`自动` / `Moyu` / `CnGal` / `YMGal` / `Bangumi` / `手动`）
  点开可以指定只从某个源重新抓取；该源没有中文简介时会**保留原来的内容**并提示，不会清空。
- **铅笔图标**
  点一下进入行内编辑，改完点「保存」。保存后会标记为**手动**，**之后重新刮削不会覆盖它**。

简介很长时默认只显示 14 行，点「展开全部」看全文。

### 5.3 换封面

详情 → 「更多设置 → **更换封面**」：

- 点「加载 VNDB 全部封面」拉取该作品在各发行版里的封面
- 每张下面标着 **分辨率 · 发行日**，可以用「最新发行 / 最高分辨率」排序，直接挑最清晰的那张
- 也可以直接粘贴图片链接，或「恢复默认」
- 超过 6 张时点「显示全部 N 张」展开

封面会被本地缓存（服务端文件缓存 + 浏览器缓存），之后离线也能看。

## 第 7 章 · 手机访问（局域网）

适合躺在床上用手机点「启动」、看收藏。

1. **手机和电脑连同一个 Wi-Fi**（同一个路由器；注意别一个连 5G 一个连 2.4G 分属不同网段的情况）
2. 回到电脑，**右键 `开启局域网访问.bat` → 以管理员身份运行**
   - 它会添加一条 Windows 防火墙规则，放行 TCP `3000-3019`（脚本会提示 `[OK] Rule added`）
   - 提示 `Administrator rights required` 就说明没用管理员身份运行，重来一次
3. 启动 MoeShelf（如果已经在跑就不用重启），看黑窗口里的这一行：

```text
Phone access (same WiFi): http://192.168.1.64:3000
```

4. 在手机浏览器里打开这个 `http://192.168.x.x:3000` 即可；也可以用手机浏览器菜单「添加到主屏幕」，当 App 用（支持 PWA）

**打不开的排查顺序**

| 现象 | 检查 |
| --- | --- |
| 手机显示无法访问 | 电脑上 MoeShelf 是否在运行？黑窗口是否还开着？ |
| 一直转圈/超时 | 防火墙规则是否添加成功（要不要以管理员重跑一次）；Windows 网络类型是不是「公用网络」（公用网络默认拦截入站，可在防火墙里放行或改成专用网络） |
| 电脑能开、手机不能 | 是否同一 Wi-Fi；路由器是否开了「AP 隔离 / 访客网络」；公司/校园网常直接禁止设备互通 |
| 换了网络后地址变了 | 局域网 IP 由路由器分配，换了 Wi-Fi 或重启路由器后黑窗口里的地址会变，看最新那行 |

## 第 8 章 · 数据、备份与迁移

所有数据都在程序目录的 `data\`：

```text
data\
├── moeshelf.db        # 主数据库（游戏库 / 游玩记录 / 刮削缓存）
├── backup\            # 自动备份（数据库一致性副本，保留最近 5 份）
├── cache\images\      # 封面等图片缓存
├── migration-backup\  # 旧版 JSON 首次迁移时的备份
├── settings.json      # 设置（根目录、地图、代理等）
└── location.json      # 数据目录定位（改过数据位置时才有）
```

- **换电脑 / 升级版本**：把整个程序目录（或至少 `data\`）复制过去即可，**无损迁移**
- **把数据放到别处**：设置 →「数据存储位置」，改路径时程序会自动迁移现有数据
- **备份**：程序每次保存都会自动备份到 `data\backup\`（保留最近 5 份）；也可以手动导出完整资料库（JSON）或 CSV 列表
- **想让刮削结果重来**：设置 →「刮削缓存」→ 清空（下次扫描会重新请求网络）
- 程序**不会**把你的游戏库、游玩记录上传到任何自有服务器；刮削时只向公开数据源请求元数据

## 第 9 章 · 常见问题排查

| 症状 | 可能原因 | 处理 |
| --- | --- | --- |
| 双击 `启动.bat` 一闪而过 | 没装 Node，或 Node 版本低于 20 | 装 Node 20+（见第 1 章）；然后在命令行里手动跑 `node -v` 确认 |
| 提示 `'node' 不是内部或外部命令` | PATH 里没有 Node | 见 1.4 / 1.5 |
| 浏览器打开是空白 / 打不开 | 黑窗口被关了，或端口不是 3000 | 重新双击 `启动.bat`；看黑窗口打印的实际 URL |
| 启动器说 3000 被占用 | 别的程序占了端口 | 用它自动选的 3001+ 即可；或关掉占用程序 |
| 扫描不到游戏 | 根目录设得太上层，或该层没有可执行文件 | 根目录设到「每个游戏一个文件夹」的那一层；检查游戏文件夹里是否有 exe |
| 卡片有封面、但没有中文简介 | 该作品在几个中文源都没有条目 | 详情里用铅笔手动写，或换个源试试（1.7.0 起可手动选源） |
| 刮削很慢 / 失败 | 网络到 vndb.org 不通 | 设置里填代理（如 `http://127.0.0.1:7890`），或开系统代理；程序在代理不可用时会自动尝试直连并提示 |
| 封面偶尔显示「加载失败」 | 图片缓存曾写入过错误响应 | 点一下「重试」即可；1.7.0 起程序会**自动清除坏缓存并重新下载**，不用手动清缓存 |
| 某个封面换了之后没变 | 浏览器缓存了旧图 | 强制刷新（`Ctrl + F5`）；必要时设置里清空缓存 |
| 杀毒软件报毒 / 拦截 | `node.exe` 被拦 | 把 MoeShelf 程序目录加进白名单（本项目不含任何可执行病毒，扫描误报较常见） |
| 手机访问不了 | 见[第 7 章](#第-7-章--手机访问局域网)的排查表 | — |
| 想彻底卸载 | — | 关闭程序 → 删掉整个程序目录即可（数据也在里面，注意先备份） |

## 第 10 章 · 从源码运行（进阶）

需要 Node.js 20+ 与 Git。

```bat
git clone https://github.com/RoxyGreyrat/MoeShelf.git
cd MoeShelf
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

生产构建与打包：

```bat
npm run build
node pack.js D:\MoeShelf-build        :: 生成「解压即用」目录
```

`pack.js` 会组装出和发布包相同的结构：`server.js` + `node_modules` + `.next` + 启动脚本 + 文档。

- 数据目录可以用环境变量覆盖：设置 `MOESHELF_DATA_DIR=D:\MoeShelf-data` 再启动
- 数据库自检：`npm run verify:sqlite`

## 第 11 章 · 桌面版 exe（当前未随版本发布）

仓库里 `desktop/` 是一个 Electron 壳，目标是**双击 exe 直接用、不需要装 Node、也不调系统浏览器**。

目前这条链路**还有问题**：CI 把 `better-sqlite3` 按 Node 22 的 ABI 编进了 Electron 运行时，启动时会报 `NODE_MODULE_VERSION 127 vs 130`，数据库打不开。所以 **Release 里暂时只有 Web 版 zip**。

如果你需要桌面版，可以自己构建（需要联网装 Electron 依赖）：

```bat
npm run build
node pack.js D:\tmp-webapp
xcopy /E /I /Y D:\tmp-webapp desktop\webapp
cd desktop
npm install
npx electron-builder --win portable --x64     :: 产物在 desktop\dist\
```

等打包流程为 Electron 重建原生模块后，桌面版会重新随版本发布。
